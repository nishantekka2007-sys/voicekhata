# Project status

VoiceKhata is in early development.

## MVP goals

1. Capture audio in a Streamlit interface.
2. Transcribe speech using a suitable speech-to-text model.
3. Extract structured transaction fields using Gemma.
4. Validate and show a reviewable transaction preview.
5. Save only confirmed transactions to SQLite.
6. Calculate customer balances with deterministic logic.
7. Test normal, ambiguous, incomplete, and failed-input cases.

## Not yet promised

Unless implementation and tests are present, production deployment, multi-user authentication, cloud synchronization, payment processing, automatic reminders, and support for every Indian language or dialect should be treated as future work.

## Demo data

Use synthetic names and amounts only. Do not store real shopkeeper or customer financial records in the repository.
