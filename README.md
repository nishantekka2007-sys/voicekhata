# VoiceKhata

**A voice-first digital ledger for Indian micro-vendors.**

VoiceKhata is an open-source hackathon project exploring how shopkeepers and small vendors can record customer credit, payments, and shop expenses using natural speech instead of typing every transaction.

> **Project status:** Early development. Features described as planned are not yet guaranteed to be implemented.

## The problem

Small vendors often track customer credit in paper notebooks or by typing into apps. VoiceKhata aims to make recording a transaction faster through a simple voice-first workflow.

## Planned MVP

- Record or upload a short audio clip.
- Transcribe speech with an open-source speech-recognition model such as Whisper/faster-whisper.
- Use an instruction-tuned Gemma model to extract transaction fields from the transcription.
- Let the vendor review and confirm the proposed transaction before saving.
- Store confirmed transactions in SQLite.
- Show customer history, outstanding balances, and a basic daily summary.
- Provide typed input as a fallback when audio or transcription fails.

## Intended technology

- Python
- Streamlit
- Gemma through a compatible local inference runtime such as Ollama
- Whisper / faster-whisper for speech-to-text
- SQLite
- Git and GitHub

The exact model versions and their applicable terms will be documented as implementation decisions are finalized. The repository's MIT license applies to this project's code, not automatically to third-party models, weights, or dependencies.

## Safety and data integrity

- AI output must be validated before it can be saved.
- Transactions require explicit user confirmation.
- Balances should be calculated by deterministic application logic, not generated by the language model.
- Ambiguous or incomplete transactions should be sent back for clarification.
- Do not use real customer financial data in demos or tests.
- Do not commit secrets, private recordings, local databases, or downloaded model weights.
